# Traffic Pulse Dashboard

Preciso de uma dashboard para gestores de trafego pago onde é possível visualizar campanhas ativas, inserir novas campanhas acompanhar onde elas estão performando seja facebook ou Instagram e me retorne os dados de quantos cliques, valores gastos e gere gráficos com base nesses dados, adicione a exclusão da campanha, add uma área para poder ser colocado vídeos para o trafego pago e crie a opção para a integração com facebook, Instagram e afins
